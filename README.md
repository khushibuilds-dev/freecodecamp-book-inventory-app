# Book Inventory

A clean, structured web page to track and organize a personal reading list of classic Indian literature and books, complete with reading status badges and visual ratings.

## Features
* **Organized Book Table:** Displays key details for each book including **Title**, **Author**, **Category**, **Status**, and **Rating**.
* **Status Tracking:** Color-coded row and badge styling for different reading states (`Read`, `In Progress`, and `To Read`).
* **Visual Rating System:** Custom CSS rating indicators (`rate two`, `rate three`, etc.) to display book ratings visually without using images or JavaScript.
* **Curated Classic Collection:** Features renowned works like *Ramayana*, *Godaan*, *Gunahon Ka Devta*, *Kalam Ka Sipahi*, and *Kabir Ke Dohe*.

## Technologies Used
* **HTML5:** Semantic `<table>`, `<thead>`, `<tbody>`, and custom class attributes for state management.
* **CSS3:** Attribute/class-based styling for status badges, row highlights, and star/dot rating indicators.

## Project Structure

1. Download or clone this repository to your local machine.
2. Open the `index.html` file in any web browser.
